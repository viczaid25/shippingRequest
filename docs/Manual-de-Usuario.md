# Manual de Usuario — Sistema de Solicitudes de Envío

**Mitsubishi Electric Automotive de México** · Guía para usuarios finales · Versión 1.0

## 1. ¿Qué es este sistema y para qué sirve?

El Sistema de Solicitudes de Envío te permite **pedir que se envíe material** (a un cliente, a un proveedor o a otra planta), ya sea dentro de México o al extranjero, y dar seguimiento a todo el proceso desde un solo lugar.

Con él puedes:

- Capturar la solicitud con todos los datos del envío, los paquetes y las fotos de evidencia.
- Recibir las **cotizaciones** de paquetería que sube el equipo de Trade y elegir la que más te convenga.
- Ver en qué paso está tu solicitud y **quién la tiene pendiente**.
- Aprobar o rechazar solicitudes, si tu puesto lo requiere.

No necesitas instalar nada: el sistema se abre desde el navegador, entrando por **Meax One**. Tu sesión se inicia con tu usuario de siempre, sin escribir contraseña adicional.

## 2. El recorrido de una solicitud (vista general)

Así avanza una solicitud, de principio a fin:

1. **Tú capturas la solicitud** (datos, direcciones, paquetes, fotos).
2. **Trade Staff revisa** tu solicitud: asigna el % de IGI, el Incoterm y el tipo de operación, y sube las cotizaciones de paquetería.
3. **Tú eliges una cotización.**
4. **Si aplica, llenas el formulario de Premium Freight** (ver sección 8).
5. **La solicitud se aprueba paso a paso** por las personas responsables (ver sección 9).
6. Al final queda **Aprobada** (o **Rechazada**, si alguien la rechazó).

Cada solicitud recibe un **folio** con el formato `SR-2026-0001` (la parte final es consecutiva). Si lleva Premium Freight, ese formulario recibe su propio folio `PF-2026-0001`. Usa siempre el folio cuando necesites preguntar por una solicitud.

### ¿Quién participa?

| Quién | Qué hace |
|---|---|
| **Solicitante** (tú) | Captura la solicitud, elige la cotización y llena Premium Freight si aplica |
| **Tu Manager** | Es el primero en aprobar tu solicitud |
| **Trade Staff** | Sube IGI, Incoterm, tipo de operación y cotizaciones; después da una aprobación formal |
| **Sales Manager / Procurement Manager** | Aprueban solo cuando hay Premium Freight que se reembolsa (ver sección 9) |
| **Finance Manager** | Aprueba y puede enviar el resumen de facturación a Finanzas |
| **President** | Aprueba todas las solicitudes |
| **Trade Manager / Trade Coordinator** | Dan las últimas aprobaciones |
| **Administradores** | Mantienen los catálogos y los permisos del sistema |

## 4. Crear una solicitud nueva

Entra a **Nueva Solicitud** en el menú. La captura se hace en **6 pasos**; arriba verás una barra que te indica en cuál vas.

> **Importante:** los campos marcados con un **asterisco rojo** son obligatorios. Si falta alguno, el sistema te lo señala y no te deja avanzar.
>
> **Se guarda sola:** cada vez que avanzas de paso se guarda un **borrador**. Si te sales a la mitad, al volver a **Nueva Solicitud** continuarás donde te quedaste.

Para moverte usa los botones **← Anterior** y **Siguiente →** al final de la pantalla. En el último paso aparece **✓ Enviar Solicitud**.

### 4.1 Paso 1 — Solicitante

**Datos del Solicitante.** El sistema llena estos datos con tu información; revísalos y corrígelos si hace falta.

| Campo | Qué debes capturar | Obligatorio |
|---|---|---|
| Nombre | Tu nombre completo | Sí |
| Email | Tu correo | Sí |
| Departamento | Tu departamento (por ejemplo, Ingeniería u Operaciones) | Sí |
| Unidad de Negocio | La planta o unidad a la que perteneces | Sí |
| Fecha | Fecha de la solicitud (hoy) | No |
| Manager / Supervisor | Tu manager. Haz clic en el campo y elige de la lista, o escribe para buscar por nombre. Esta persona será la **primera en aprobar** tu solicitud | Sí |

Una vez elegido, el manager aparece en una tarjeta con su nombre y correo. Si te equivocaste, usa el botón **Cambiar**.

> La lista de managers solo muestra personas con puesto de gerencia. Si no encuentras a la persona que buscas, avisa a Procurement.

**Tipo de Envío.**

| Campo | Qué debes elegir | Obligatorio |
|---|---|---|
| Alcance | **Nacional** (dentro de México) o **Internacional** | Sí |
| Categoría | Solo si el alcance es Nacional: **Compras** o **Traslado** | Sí (si es Nacional) |
| Dirección | Solo si el alcance es Internacional: **Export** (sale de México) o **Import** (entra a México) | Sí (si es Internacional) |

### 4.2 Paso 2 — Direcciones

Aquí capturas quién es el comprador y a quién se le entrega el envío. En ambos bloques hay un buscador **"Elegir del catálogo de clientes"**.

**Cómo usar el catálogo de clientes:** haz clic en el campo y escribe parte del nombre, del código, del RFC o de la ciudad. Elige al cliente de la lista y el sistema **llena solos** la razón social, el RFC/Tax ID y la dirección. Puedes corregir cualquier dato después. Si el cliente no está en el catálogo, captura los datos a mano.

**Información del Comprador** (todos opcionales)

| Campo | Qué debes capturar |
|---|---|
| Razón Social | Nombre de la empresa compradora |
| Tax ID / RFC | RFC (México) o Tax ID (extranjero) |
| Dirección | Calle, ciudad, estado, código postal y país |

**Recolección / Destinatario** — datos de quien recibe el envío

| Campo | Qué debes capturar | Obligatorio |
|---|---|---|
| Razón Social | Nombre de la empresa que recibe | Sí |
| Tax ID / RFC | RFC o Tax ID de quien recibe | No |
| Dirección | Calle, ciudad, estado, código postal y país | Sí |
| Atención a | Nombre de la persona de contacto | No |
| Teléfono | Teléfono de contacto | No |
| Correo | Correo de contacto | No |

### 4.3 Paso 3 — Envío

**Detalles del Envío**

| Campo | Qué debes elegir o capturar | Obligatorio |
|---|---|---|
| Vía de Envío | **Marítimo**, **Terrestre** o **Aéreo** | No (ya viene marcada una) |
| Tipo de Servicio | **Urgente** o **Económico** | No (ya viene marcado uno) |
| Fecha de Entrega | Fecha en que necesitas que llegue. **Debe ser posterior a hoy** | No |
| Propósito del Envío | Explica el motivo del envío | Sí |

**Información de Factura**

| Campo | Qué debes elegir o capturar | Obligatorio |
|---|---|---|
| Tipo de Factura | **Comercial** o **Traslado** | No (ya viene marcado uno) |
| Tramos de Flete Aplicables | Marca uno o más: **Flete Local Origen**, **Flete Local Destino**, **Flete Internacional**. Indican qué partes del trayecto hay que cubrir | Sí, al menos uno |
| Número de Factura | Solo aparece en envíos Internacionales de tipo Import | No |

> **No te preocupes por el Incoterm, el Certificado de Origen ni el Tipo de Operación.** Esos datos los define el equipo de Trade Staff durante su revisión.

**Opciones Logísticas**

| Campo | Qué debes elegir o capturar | Obligatorio |
|---|---|---|
| ¿Es Estibable? | **Sí** (la carga se puede apilar) o **No** (no debe apilarse) | Sí |
| Seguro de Envío | Interruptor: actívalo si el envío requiere seguro | No |
| Responsabilidad de Pago | **Meax** (la empresa paga el envío) o **Receiver** (paga quien recibe) | No (ya viene marcado Meax) |
| Parcel Account | Número de cuenta de paquetería de quien recibe. Solo aparece si eliges **Receiver** | Sí (si es Receiver) |
| Paquetería | **FedEx**, **UPS**, **DHL** u **Otro**. Solo aparece si eliges **Receiver** | No |

### 4.4 Paso 4 — Paquetes e Items

Aquí describes **qué se va a enviar y cómo va empacado**. Puedes agregar:

- **Pallet** (tarima) con cajas dentro, o con items sueltos.
- **Caja** sola.

Usa los botones **Agregar Pallet** o **Agregar Caja**. Dentro de un pallet usa **+ Caja** para agregar cajas y **+ Item** para agregar partidas. El botón **✕** elimina el pallet, la caja o el item. Con la flecha ▲/▼ del encabezado puedes expandir o contraer cada bloque.

**Datos de cada pallet o caja**

| Campo | Qué debes capturar |
|---|---|
| Etiqueta / Referencia | Un nombre para identificarlo (por ejemplo, "Pallet A" o "Caja 1") |
| Peso Bruto | Peso **total** de esa caja o pallet, con empaque, en **kg** |
| Largo, Ancho, Alto | Medidas de esa caja o pallet completo, en **cm** |

> El peso bruto y las medidas se capturan **una sola vez por caja o pallet**, no por cada item.
>
> **Regla del peso:** si capturas el peso bruto, debe ser **mayor** que la suma de los pesos netos de los items que van dentro. Si no, el sistema te muestra un aviso y no te deja avanzar.

**Datos de cada item (una fila por partida)**

| Campo | Qué debes capturar |
|---|---|
| No. Parte | Número de parte. Al escribir, el sistema sugiere números del catálogo |
| Clase | Clase o tipo de material |
| Descripción | Descripción del material |
| Cant. | Cantidad (mínimo 1) |
| UOM | Unidad de medida: PCS, KG, LB, BOX, PLT, EA o SET |
| Peso Neto | Peso del material **sin** empaque, en kg |
| Unit Price | Precio unitario |
| Amount | Se calcula solo (cantidad × precio) |

### 4.5 Paso 5 — Evidencias fotográficas

Debes subir **4 fotografías**, todas obligatorias:

| Foto | Qué debe mostrar |
|---|---|
| **Peso Neto** | Una foto que respalde el peso del material sin empaque (por ejemplo, la báscula) |
| **Peso Bruto** | Una foto que respalde el peso del material ya empacado (por ejemplo, la báscula) |
| **Dimensiones** | Una foto que respalde las medidas del bulto (por ejemplo, con flexómetro) |
| **Empaque Final** | Cómo quedó el empaque terminado. **Si el paquete lleva etiqueta, fotografíala y súbela también** |

Para cada una, haz clic en **Seleccionar Foto** y elige el archivo. Reglas:

- Solo se aceptan imágenes **JPG o PNG**.
- Cada imagen puede pesar **hasta 8 MB**.
- Si te equivocas de foto, usa el botón **Cambiar**.

### 4.6 Paso 6 — Observaciones y envío

| Campo | Qué debes capturar | Obligatorio |
|---|---|---|
| Observaciones | Cualquier nota o comentario adicional | No |
| Folio Baja de Material (MX-7104-F1) | El folio del formato de baja de material, si aplica | No |
| Motivo por el que no aplica el Folio | Aparece cuando dejas vacío el folio anterior; explica por qué no hay folio | Sí (si no hay folio) |

Al final verás un aviso informativo: el porcentaje de IGI y el costo del envío los determina Trade Staff, quienes subirán las cotizaciones para que elijas la más conveniente.

Cuando todo esté listo, presiona **✓ Enviar Solicitud**. El sistema te llevará al detalle de tu solicitud, ya con su folio **SR-…**. A partir de ese momento ya no se puede editar desde el sistema; si te equivocaste, avisa a Procurement o a Trade.

## 5. Ver y seguir tus solicitudes

### 5.1 Mis Solicitudes

Muestra la lista de solicitudes registradas. Cada renglón indica el folio y el destinatario, el departamento, la vía y el tipo de servicio, la fecha, el **estado** y, cuando el monto es de 5,000 USD o más, el importe. Haz clic en un renglón para abrir su detalle.

- Con **+ Nueva** puedes empezar otra solicitud.
- Si tienes un **borrador** sin terminar, aparece con el estado **Borrador**; al hacer clic continúas la captura.

### 5.2 Detalle de la solicitud

Es la ficha completa de una solicitud. En la parte superior ves el folio, el destinatario y el **estado actual**. Más abajo hay tarjetas con la información:

| Tarjeta | Qué contiene |
|---|---|
| Solicitante | Quién la pidió, su departamento y su manager |
| Destinatario | A quién se envía y cómo contactarlo |
| Envío | Folio, vía, servicio, fecha de entrega, propósito, si es estibable y si lleva seguro |
| Factura | Tipo de factura, Incoterm, tramos de flete, % IGI, si lleva Certificado de Origen y el Tipo de Operación |
| Pago | Quién paga, Parcel Account y paquetería, folio de baja y observaciones |
| Comprador | Datos del comprador |
| Cotizaciones de Envío | Las cotizaciones subidas por Trade; puedes abrir el PDF de cada una |
| Premium Freight | Los datos de ese formulario, si aplica |
| Evidencias Fotográficas | Las 4 fotos (clic para verlas en grande) |
| Flujo de Aprobación | La línea de tiempo con cada aprobador, su decisión, fecha y comentarios |

Algunos datos aparecen como **"Pendiente — lo asigna Trade Staff"** (Incoterm y Tipo de Operación) hasta que Trade Staff los define.

Cuando **te toca hacer algo** en esa solicitud, aparece una tarjeta de **"Acción Requerida"** con el botón correspondiente.

## 6. Elegir la cotización (solicitante)

Cuando Trade Staff termina de subir las cotizaciones, tu solicitud pasa a **"Pendiente — Selección de Cotización"**. Abre la solicitud y presiona **Ver y Elegir Cotización**.

En la pantalla verás:

- El **% IGI** que asignó Trade Staff.
- Un aviso del tipo de factura (Comercial o Traslado) que te indica si se requerirá Premium Freight.
- Una **tarjeta por cotización**, ordenadas de la más económica a la más cara, con proveedor, monto y notas. Puedes abrir el PDF de cada una.

Haz clic en la tarjeta que quieras; se marca como **✓ Seleccionada**. Luego presiona **Confirmar Selección →**.

> Puede haber **una sola cotización** (por ejemplo, cuando se usa la cuenta del cliente o del proveedor). En ese caso solo debes seleccionarla y confirmar.

Después de confirmar:

- Si la factura es **Comercial**, o la cotización elegida es de **5,000 USD o más**, el sistema te pedirá llenar **Premium Freight** (siguiente sección).
- Si no, la solicitud pasa directo a aprobación.

## 7. Premium Freight (solo cuando aplica)

**Premium Freight** es un envío que requiere información adicional porque es de alto costo (5,000 USD o más) o porque la factura es comercial. Se llena en una pantalla con estos campos:

**Información general**

| Campo | Opciones |
|---|---|
| Dirección | Import, Export o Local |
| Alcance | Nacional, América, Europa, Asia u Otro |
| Tipo de Transporte | Air Freight, Land Freight, Sea Freight, Charter u Otro |
| Responsabilidad de Pago | **Pagado por Meax**, **Reembolsable por Proveedor** o **Reembolsable por Cliente** |

> La **Responsabilidad de Pago** es importante: determina si además deberán aprobar el área de **Ventas** (si lo reembolsa el cliente) o **Procurement** (si lo reembolsa el proveedor).

**Pick Up At (de dónde se recoge) y Delivery At (a dónde se entrega)**

| Campo | Qué debes capturar | Obligatorio |
|---|---|---|
| Nombre | Nombre del lugar o empresa | No |
| Dirección | Dirección completa | Sí |
| Persona de Contacto | Quién atenderá la recolección o la entrega | No |

**Explicación del envío**

| Campo | Qué debes capturar | Obligatorio |
|---|---|---|
| Causa Raíz del Envío | Qué originó la necesidad de este envío y de qué producto se trata | Sí |
| Countermeasures | Las medidas correctivas para que no se repita | Sí, cuando la solicitud es de 5,000 USD o más |
| Forwarder | Nombre del agente de carga | No |

Al terminar presiona **✓ Enviar a Aprobación**. Si necesitas cambiar tu elección de cotización, usa **← Cambiar Cotización**.

## 8. Qué hace Trade Staff (revisión y cotizaciones)

*Esta sección es para el equipo de Trade Staff. Si eres solicitante, es útil para saber qué ocurre con tu solicitud.*

Cuando una solicitud llega a Trade Staff, aparece en **Pendientes** y, al abrirla, la tarjeta **"Acción Requerida — Trade Staff"** con el botón **Ingresar IGI y Cotizaciones**. Cualquier persona con el rol Trade Staff puede hacerlo.

La pantalla **Revisión Trade Staff** tiene:

| Campo | Qué se captura | Obligatorio |
|---|---|---|
| % IGI | Porcentaje de impuesto de importación (mayor a 0) | Sí |
| Incoterm Aplicable | Término de comercio: EXW, FCA, FAS, FOB, CFR, CIF, CPT, CIP, DAP, DPU o DDP | Sí |
| Tipo de Operación | **A1** o **RT**. Empieza vacío y se debe elegir | Sí |
| Certificado de Origen (COO) | Interruptor "Este envío requiere Certificado de Origen"; si se activa, hay que subir el documento en PDF | Solo si se activa |
| Cotizaciones de Envío | Desde 1 y hasta 5 cotizaciones (ver abajo) | Sí, mínimo 1 |

El tablero muestra también un resumen de la solicitud y qué tramos de flete marcó el solicitante, para decidir el Incoterm.

**Cada cotización** lleva:

| Campo | Qué se captura | Obligatorio |
|---|---|---|
| Proveedor | Nombre de la paquetería o proveedor | Sí |
| Monto (USD) | Costo en dólares (mayor a 0) | Sí |
| Notas / Condiciones | Por ejemplo, tiempo de entrega o tránsito | No |
| PDF de Cotización | Archivo PDF de la cotización (hasta 10 MB) | Sí |

El formulario abre con **una** cotización. Para agregar más usa **+ Agregar Cotización** (máximo 5); con **✕ Eliminar** quitas las que sobren. Cuando solo se usa la cuenta del cliente o del proveedor, basta con una.

Al terminar, **Guardar y Enviar al Usuario** pasa la solicitud al solicitante para que elija.

## 9. Aprobaciones

### 9.1 Quiénes aprueban y en qué orden

Después de elegir la cotización (y llenar Premium Freight si aplica), la solicitud recorre este orden:

| Orden | Quién aprueba | ¿Siempre? |
|---|---|---|
| 1 | **Manager** del solicitante | Sí |
| 2 | **Sales Manager** (Ventas) | Solo si el Premium Freight es *Reembolsable por Cliente* |
| 3 | **Procurement Manager** | Solo si el Premium Freight es *Reembolsable por Proveedor* |
| 4 | **Finance Manager** (Finanzas) | Sí |
| 5 | **President** (Presidencia) | Sí |
| 6 | **Trade Staff** (aprobación formal) | Sí |
| 7 | **Trade Manager** | Sí |
| 8 | **Trade Coordinator** | Sí |

Cada persona solo puede actuar cuando **le llega su turno**. Si alguien rechaza, la solicitud termina como **Rechazada**.

### 9.2 La pantalla "Pendientes"

En **Pendientes** ves únicamente las solicitudes que están esperando **tu** acción. Cada tarjeta muestra el folio, el destinatario, el departamento, la vía, la fecha, el estado y en qué **paso** estás ("Paso: …"). Haz clic para abrirla.

Si no tienes nada pendiente verás el mensaje *"Sin aprobaciones pendientes para tu rol"*.

### 9.3 Cómo aprobar o rechazar

1. Abre la solicitud desde **Pendientes**. Revisa su información, las cotizaciones y las evidencias.
2. En la tarjeta **"Acción Requerida"** presiona **✓ Aprobar Solicitud** o **✕ Rechazar Solicitud**.
3. Se abre una ventana de confirmación con un campo de **Comentarios**:
   - Al **aprobar**, los comentarios son **opcionales**.
   - Al **rechazar**, los comentarios son **obligatorios**: explica el motivo.
4. Confirma con **✓ Aprobar** o **✕ Rechazar**.

> **Rechazar es definitivo**: la solicitud ya no continúa. Revisa bien antes de confirmar.

Los comentarios quedan registrados en el **Flujo de Aprobación** de la solicitud.

### 9.4 Resumen de facturación para Finanzas

La persona de Finanzas asignada a la solicitud verá la tarjeta **"Facturación — Finanzas"** con el botón para **enviar el resumen de facturación por correo**. El correo incluye los datos generales, los paquetes y la cotización elegida en PDF.

## 10. Estados de una solicitud

El estado aparece como una etiqueta de color en la lista y en el detalle:

| Estado | Qué significa | Quién tiene que actuar |
|---|---|---|
| **Borrador** | Empezaste la captura y no la has enviado | El solicitante |
| **Pendiente — Trade Staff (IGI/Cotizaciones)** | Esperando que Trade Staff capture IGI, Incoterm y cotizaciones | Trade Staff |
| **Pendiente — Selección de Cotización** | Hay cotizaciones listas para elegir | El solicitante |
| **Pendiente — Premium Freight** | Falta llenar el formulario de Premium Freight | El solicitante |
| **Pendiente — Manager de Usuario** | Espera la aprobación del manager | El manager |
| **Pendiente — Ventas** | Espera la aprobación de Ventas | Sales Manager |
| **Pendiente — Procurement** | Espera la aprobación de Procurement | Procurement Manager |
| **Pendiente — Finanzas** | Espera la aprobación de Finanzas | Finance Manager |
| **Pendiente — Presidencia** | Espera la aprobación de Presidencia | President |
| **Pendiente — Aprobación Trade Staff** | Espera la aprobación formal de Trade Staff | Trade Staff |
| **Pendiente — Trade Manager** | Espera la aprobación de Trade Manager | Trade Manager |
| **Pendiente — Trade Coordinator** | Espera la última aprobación | Trade Coordinator |
| **Aprobado** | Terminó todo el proceso | — |
| **Rechazado** | Alguien la rechazó | — |

## 11. Administración (solo administradores)

La opción **Administración** del menú solo aparece para administradores del sistema. Desde ahí se gestiona:

| Sección | Para qué sirve |
|---|---|
| **Configuración (permisos)** | Asignar a las personas que ocupan cada rol de aprobación: Trade Staff, Trade Coordinator, Trade Manager, Procurement Manager, Sales Manager, Finance Manager y President |
| **Administradores** | Agregar o quitar a quienes pueden administrar el sistema |
| **Catálogo de números de parte** | Agregar números de parte (con descripción y clase), o activarlos y desactivarlos. Se usan para sugerir al capturar items |
| **Catálogo de clientes** | Agregar, editar, activar o desactivar clientes y destinos. Aparecen en el buscador de los pasos de direcciones |

**Para agregar a una persona a un rol o como administrador:** presiona el botón de agregar, escribe parte de su nombre, correo o usuario, elige a la persona de la lista y confirma.

**Para el catálogo de clientes:** presiona **+ Nuevo Cliente** y llena código, razón social (obligatoria), RFC/Tax ID, calle, colonia, ciudad, estado, código postal, país y moneda. Con **Editar** modificas un cliente existente, y **Desactivar** lo oculta del buscador sin borrarlo. Si un cliente tiene varios domicilios, se registra una vez por cada domicilio.

## 12. Preguntas frecuentes y consejos

**No encuentro a mi manager en la lista.**
La lista solo incluye personas con puesto de gerencia. Escribe parte de su nombre para buscarlo; si no aparece, avisa a Procurement.

**Mi cliente no aparece en el catálogo.**
Captura sus datos manualmente. Si es un cliente frecuente, pide a un administrador que lo agregue al catálogo.

**No me deja avanzar al siguiente paso.**
Revisa que todos los campos con asterisco rojo estén llenos. Los campos con problema se marcan en rojo con un mensaje debajo.

**El sistema dice que el peso neto debe ser menor al peso bruto.**
El peso bruto de una caja o pallet debe ser mayor que la suma de los pesos netos de los items que contiene. Revisa los números.

**No puedo subir una foto.**
Verifica que sea JPG o PNG y que pese menos de 8 MB. Si aparece un mensaje de "acceso denegado", avisa a TI: es un tema del servidor, no de tu foto.

**Me salí a la mitad de la captura.**
No pierdes nada: se guarda un borrador cada vez que avanzas de paso. Entra a **Nueva Solicitud** y continúa.

**Ya envié la solicitud y me equivoqué en un dato.**
El sistema no permite editar una solicitud enviada. Avisa a Procurement o a Trade para saber cómo corregirla.

**¿Cómo sé en qué punto va mi solicitud y a quién le toca?**
Abre la solicitud y revisa la tarjeta **Flujo de Aprobación**, o fíjate en el estado.

**Mi sesión se cerró o veo una pantalla de inicio de sesión.**
Vuelve a entrar desde **Meax One**; el sistema te reconocerá con tu usuario.

**Consejos para que tu solicitud avance sin retrasos**

- Captura el **propósito del envío** con claridad: lo leerán todos los aprobadores.
- Toma las **4 fotos** con buena luz y que se lean las básculas y las etiquetas.
- Elige bien al **manager**: sin su aprobación la solicitud no avanza.
- Usa el **catálogo de clientes** para evitar errores de captura en razón social, RFC y dirección.
- Si tienes **aprobaciones pendientes**, revisa **Pendientes** con frecuencia: tu respuesta rápida acelera a todos.

## 13. Glosario

| Término | Significado |
|---|---|
| **Folio (SR / PF)** | Número único de la solicitud (`SR-2026-0001`) o de su formulario de Premium Freight (`PF-2026-0001`) |
| **Incoterm** | Término internacional de comercio que define quién paga y quién asume el riesgo en cada parte del envío. Lo asigna Trade Staff |
| **IGI** | Impuesto General de Importación, expresado como porcentaje. Lo asigna Trade Staff |
| **COO** | Certificado de Origen: documento que indica en qué país se fabricó la mercancía |
| **Tipo de Operación (A1 / RT)** | Clave con la que Trade clasifica la operación aduanera. La define Trade Staff |
| **Premium Freight** | Envío de alto costo (5,000 USD o más) o con factura comercial, que requiere explicar su causa y las medidas correctivas |
| **Cotización** | Oferta de costo de una paquetería o proveedor para realizar el envío |
| **Estibable** | Que la carga puede apilarse sobre otra |
| **Pallet** | Tarima sobre la que se acomodan cajas o material |
| **Peso Neto / Peso Bruto** | Neto: peso del material sin empaque. Bruto: peso con empaque |
| **UOM** | Unidad de medida del material (piezas, kilos, libras, etc.) |
| **Tax ID / RFC** | Identificación fiscal de la empresa (RFC en México, Tax ID en el extranjero) |
| **Parcel Account** | Número de cuenta de paquetería de quien recibe, cuando él paga el envío |
| **Receiver** | Quien recibe el envío |
| **Forwarder** | Agente de carga que organiza el transporte |
| **Folio de Baja de Material (MX-7104-F1)** | Folio del formato interno con el que se da de baja material |
| **Meax One** | Portal corporativo desde el que se entra a este sistema |
